# ASCII mockups before UI code

Sketch, don't build. At most three genuinely different layout hypotheses,
ASCII only, no code.

1. Fix a legend (`┌─┐ │ └─┘ ░ ≈ [ ] ( )`); keep sketches 60-80 columns and
   8-20 rows.
2. Per hypothesis: regions, which existing components are reused (by their
   real names) and which are new, the empty/loading/populated/error states,
   and where navigation goes.
3. Recommend one. Ask at most one question, then stop. Say when ASCII cannot
   settle it (density, motion, brand) and a hi-fi prototype is needed.

The sketch and the chosen option go into the spec only if a spec exists;
otherwise they stay in the conversation.
